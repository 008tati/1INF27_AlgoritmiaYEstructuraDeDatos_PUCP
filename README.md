## Sobre este repositorio

Algoritmia puede parecer intimidante, pero se vuelve más accesible con cada problema que resuelves. Aquí encontrarás los enunciados de laboratorios y exámenes de ciclos anteriores de Algoritmia y Estructura de Datos de la PUCP, para que practiques con evaluaciones reales y llegues a cada examen con confianza 🚀

---

## Temas por evaluación

Temas evaluados en el 2026-2. En ciclos anteriores el orden de los temas puede variar.

| Evaluación | Temas |
| :--- | :--- |
| **Lab 1** | Fuerza bruta y Recursión |
| **Lab 2** | Recursión y Listas |
| **Lab 3** | Listas y Pilas |
| **Lab 4** | Divide y vencerás |
| **Lab 5** | Árbol Binario de Búsqueda (ABB) |
| **Examen 1** | Fuerza bruta, Recursión, Listas, Pilas y Colas |
| **Examen 2** | Cola, Divide y vencerás, ABB |
